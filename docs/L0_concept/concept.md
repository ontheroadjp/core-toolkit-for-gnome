# コンセプト

## 目的

このリポジトリは、Ubuntu / GNOME 環境の設定と必要なツールを
バージョン管理し、環境をゼロから構築・再構築しやすくする。

## 解決する問題

OS の再インストールやマシンの更新時に、デスクトップの挙動、
アプリケーションの設定、必要なツールを手作業で再構築する負担を減らす。

## 対象

Ubuntu で GNOME を利用するユーザーを対象とする。

Ubuntu のバージョンや実行環境によって処理が異なる場合は、
必要に応じて条件分岐する。

## 設計上の制約

- ハードウェア固有の設定は、機種を問わず利用する設定から分離する。
- 構成を簡潔に保ち、抽象化や汎用化は必要最小限にとどめる。
- デスクトップ環境の設定とセットアップを対象とし、
  独立したアプリケーションの開発は対象に含めない。
